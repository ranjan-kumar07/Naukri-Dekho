# Job Portal Web Application

A modern Job Portal Web Application built using Django and Bootstrap where recruiters can post jobs and users can apply for opportunities online.

---

# Features

## Recruiter Features
- Recruiter Dashboard
- Post New Jobs
- View Posted Jobs
- View Applications
- Accept Candidates
- Professional Bootstrap UI

## User Features
- User Dashboard
- Browse Jobs
- Apply for Jobs
- Upload Resume
- Cover Letter Submission

## Authentication
- Register/Login System
- Role Based Authentication
- Recruiter & User Separation

# Installation

## 1. Clone Repository

```bash
git clone https://github.com/ranjan-kumar07/Naukri-Dekho.git
```

## 2. Move Into Project

```bash
cd job-portal
```

## 3. Create Virtual Environment

```bash
python -m venv venv
```

## 4. Activate Virtual Environment

### Windows

```bash
venv\Scripts\activate
```

### Linux/Mac

```bash
source venv/bin/activate
```

---

# Install Dependencies

```bash
pip install -r requirements.txt
```

---

# Run Migrations

```bash
python manage.py makemigrations
python manage.py migrate
```

---

# Start Development Server

```bash
python manage.py runserver
```

Open browser:

```bash
http://127.0.0.1:8000/
```
